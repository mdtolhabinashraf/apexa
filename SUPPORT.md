# Support

For questions and bug reports, use the repository's issue tracker once it is configured.

Please include:

- Apexa version.
- Node.js/browser and operating system versions.
- TypeScript version, if applicable.
- A minimal reproduction.
- Expected behavior and actual behavior.
- Relevant sanitized error codes and messages.

Do not post access tokens, cookies, passwords, API keys, or private payloads.

Feature requests should describe the problem to solve and, where possible, include a proposed API and example.
